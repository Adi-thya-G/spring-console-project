Student Management System --- Spring Boot Console App
A small beginner-friendly Spring Boot console project for managing
student information.

The application lets you add, view, update, and remove students. Student
records are stored in a Java List while the application is running.
Important: The list starts empty every time the application
starts. This project does not use a database or save data permanently.

Features
- Add a student
- Display all students
- Find a student by ID
- Update student details
- Remove a student
- Show a message when the list is empty or a student is not found
